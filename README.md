# Hall AI Ver.1.0

ChatGPTで作成したホール分析を、スマートフォン内に保存・閲覧するためのローカルPWAです。
サーバー、外部API、クラウドデータベースは使用しません。

## 主な機能

- 今日の狙い目と最終判断（GO／GO慎重／様子見／撤退）
- 期待値とAI信頼性の分離表示
- 店舗DNA
- 機種・イベント別の癖カード
- 営業結果を使った自己学習補正
- 判断・学習の監査ログ
- ChatGPT更新データ `HALL_AI_UPDATE_V2` / `V3` の取り込み
- バックアップ書き出し・復元
- 旧RC版およびVer.5からの自動移行
- オフライン利用対応

## GitHub Pagesへの更新方法

1. ZIPを展開します。
2. リポジトリ直下の既存ファイルを、展開したファイルで置き換えます。
3. `index.html`、`manifest.webmanifest`、`sw.js`、`README.md`、`update-example.json` をコミットします。
4. GitHub Pagesを開き、古い画面が出る場合はページを再読み込みします。

## 毎朝の使い方

1. ChatGPTへホール分析を依頼します。
2. 回答末尾のHall AI更新データをコピーします。
3. Hall AIの「更新」画面へ貼り付けます。
4. 「更新内容を確認」後、「確認した内容で更新」を押します。
5. 「今日」画面で店舗・イベント・日付を選びます。

## 注意

Hall AIは判断支援ツールです。予測や収支を保証するものではありません。保存データは端末内にあるため、定期的にバックアップを書き出してください。
